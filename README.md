## 📌 About the Project

WomenCrimeInfoBot is a web-based crime awareness and analytics platform designed to make historical crime statistics more accessible and understandable.

The application combines an interactive dashboard with a chatbot interface. The dashboard helps users explore historical data related to crimes against women in India, while the chatbot provides a conversational way to access relevant crime-related information.

The project aims to use web technologies, data visualization, and conversational AI to support public awareness and encourage informed exploration of crime statistics.

## ✨ Features

- **Interactive Crime Dashboard:** Explore available crime statistics through a visual interface.
- **Historical Data Analysis:** Work with data covering crimes against women in India from 2001 to 2021.
- **Crime Trend Exploration:** Understand patterns in the available historical data.
- **Conversational Chatbot:** Access crime-related information through a question-and-answer interface.
- **User-Friendly Interface:** Navigate the dashboard and chatbot through a simple web application.
- **Social Awareness:** Make historical crime information easier to access and understand.

## 📊 Dataset

The project uses historical data related to crimes against women in India, covering the period from **2001 to 2021**.

The dataset supports the exploration and presentation of crime statistics through the application's analytics interface.

The analysis is intended to help users understand the available historical information. The results depend on the coverage, accuracy, and completeness of the underlying dataset.

## ⚙️ How It Works

1. **Data Input:** Historical crime data provides the basis for the analytics dashboard.
2. **Data Presentation:** Relevant information is organized and displayed through the user interface.
3. **Interactive Exploration:** Users explore the available statistics and trends.
4. **Chatbot Interaction:** Users ask questions through the chatbot to access relevant information.
5. **Awareness:** The application helps users engage with crime-related information in an accessible format.

## 🚀 Getting Started

Follow these steps to run the frontend application locally.

### Prerequisites

Ensure that the following tools are installed:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/namumore5143/womencrimebot-UI.git
```

**2. Navigate to the project directory**

```bash
cd womencrimebot-UI
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal. With the default Vite configuration, it is usually:

```text
http://localhost:5173
```
